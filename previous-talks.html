Anomaly Detection in Digital Elevation Models

Date: August 21, 2025

The National Map provides digital elevation, lidar, and hydrography data for the United States. Data is collected by contractors and manually reviewed by the USGS. This talk explores how computer vision and statistical methods can automate parts of the QA/QC process for digital elevation models.

Pydantic

Date: July 17, 2025

Parse, Don't Validate. This talk explains how to incorporate the Pydantic parsing and validation library into your application. Learn how Pydantic allows you to define the shape of your data using pure Python for safer and more understandable code. The session includes an overview of what Pydantic is, how it works, and real-world use cases.

Deploying and Monitoring AI Models

Date: June 19, 2025

This talk discusses methods for deploying asynchronous machine learning models to detect cracks in bridges using drone inspection data. It covers the use of Celery with Python and RabbitMQ for scheduling ML tasks, and demonstrates how to use Grafana and Prometheus to monitor computational server loads.
Note: This talk was hosted before PYSTL meetup was set up
